## 📖 简介

**Chest Cavity Legacy** 是模组 *Chest Cavity* 在 Minecraft 1.12.2 Forge 平台的移植版本。

模组为游戏内的所有生物赋予了一套高度可定制的**胸腔与内脏器官系统**。每个生物内部都拥有一套可交互的胸腔物品栏，代表它们的脏器与内部构造。玩家可以使用**开胸器**查看、剖析或替换实体体内的器官，通过丰富的**器官评分系统**全方位塑造生物的能力属性。

模组基于 **CleanroomMC ModularUI** 构建了现代化的自适应交互界面，深度整合 **CraftTweaker**，为整合包作者提供了从器官数据、生物胸腔尺寸到主动技能轮盘的完全定制能力。

## ⚙️ 核心机制

### 1. 胸腔系统 (Chest Cavity)
每个 `EntityLivingBase` 通过 Forge Capability 附加 `IChestCavity` 能力：
- **动态网格尺寸**：默认 9×3（27 格），**全面支持动态尺寸**（可通过 CraftTweaker 针对胸腔类型或实体单独设置任意列数与行数，如 4×2、9×6、12×9 等）。
- **自适应界面**：基于 ModularUI 构建，配备专属GUI贴图（材质来自《脆骨症》授权），支持自适应边框平铺与居中网格排版。
- **器官评分判定**：每个器官提供多种属性评分，实时的生理属性与能力均由当前器官评分决定。
- **固有底分机制**：胸腔类型可配置固有基础分数（`baseOrganScores`），代表肉身天生具有的底分（即使掏空器官亦生效），避免骷髅等无肉身生物失去行动力。

### 2. 开胸与手术
- **开胸条件**：
  - 目标实体**不可穿着胸甲**；
  - 需满足虚弱阈值（当前生命值 ≤ 20 点 或 ≤ 最大生命值的 50%），**或者**胸腔中拥有 `ease_of_access`（开胸便利性）评分；
  - 玩家对自己开胸无距离与虚弱限制。
- **手术创伤**：
  - 若目标体内不含 `ease_of_access`(门)，开胸过程将对目标造成创伤伤害（默认 4 点，伤害值及是否致死可在配置文件中设置）。
  - 若包含 `ease_of_access`，则可实现无创无痛即时开启。
- **权限与保护**：配置项可独立控制是否允许玩家互相开胸。

### 3. 器官获取与屠宰
- 使用**剁刀**（木 / 石 / 金 / 铁 / 钻石）击杀生物可有效获取其器官。
- 未打开过胸腔的生物在自然死亡时也会按概率掉落器官（受抢夺附魔影响）。
- 附魔对获取的影响：
  - **外科手术**：每级大幅提高器官掉落概率（等效 +2 抢夺）。
  - **医疗事故诅咒**：击杀时掉落的器官会被标记为不兼容。
  - **手术恐惧症**：完全阻止生物掉落器官。

### 4. 器官兼容性与排异
- **无标记器官**：通用兼容，任意生物均可移植。
- **所有者绑定**：带有归属标记的器官仅兼容原始宿主。
- **排异反应**：强行移植不兼容器官会触发周期性排异伤害，不兼容程度越高发作越频繁（排异伤害与频率可在配置中调整或完全关闭）。
- **O 型阴性附魔**：
  - I 级：抹除所有者标记，实现万能兼容；
  - II 级：死亡时保留该器官，不随死亡掉落。

### 5. 器官低保机制 (Welfare Organs)
- 为了避免玩家因器官掏空、死亡惩罚或意外变故陷入“复活即暴毙/永久瘫痪”的恶性死循环，模组引入了**核心生命维持器官低保救济机制**。
- 当玩家复活或处于极度衰弱状态时，若以下核心生理评分 ≤ 0，系统将自动补发救济器官：
  - 缺失生命值（`health`）时发放 **腐烂心脏**
  - 缺失呼吸恢复（`breath_recovery`）时发放 **腐烂肺**
  - 缺失神经（`nerves`）时发放 **腐烂脊柱**
  - 缺失力量（`strength`）时发放 **腐肉**
- 若胸腔已满，会自动替换指定槽位并将被挤出的物品安全返还或掉落。

- **开胸器 (Chest Opener)**：用于打开自身或目标生物胸腔的不可堆叠工具。
- **剁刀 (Cleavers)**：木、石、金、铁、钻石材质，具有更高的伤害与屠宰器官掉落率。

### 伪器官系统 (Pseudo-Organs)
并非只有生物肉体器官才能放入胸腔！原版物品与方块也可作为“伪器官”植入：
- **不会触发器官排斥**，不记录所有者标签。
- **方块类**：泥土（填充基础体积）、熔炉（熔炉供能）、活塞（跳跃与冲力）、黑曜石/铁块/金块/钻石块/绿宝石块（超高防御与特殊抗性）、荧石/铁栏杆/骨块等。
- **物品类**：骨头、腐肉、火药（爆炸属性）、烈焰棒（耐火与发热）、荧石粉（发光）、粘液球（弹力）、TNT（自爆）等。
- **食物类**：熟猪排、牛排、羊肉等（提供缓释营养储备）。

## ✨ 附魔与控制

### 附魔列表

| 附魔 | 适用物品 | 最高等级 | 稀有度 | 效果 |
|---|---|---|---|---|
| **O 型阴性 (O-Negative)** | 器官物品 | II | 稀有 | **I 级**：抹除所有者，任何生物均可移植且无排斥；<br>**II 级**：死亡保留，玩家死亡后此器官依然保留在胸腔中。 |
| **外科手术 (Surgical)** | 剁刀武器 | III | 非常稀有 | 每级提升屠宰时的器官掉落概率（等效抢夺加成）。 |
| **医疗事故诅咒 (Curse of Malpractice)** | 剁刀武器 | I | 非常稀有 | 诅咒附魔。击杀时掉落的器官会被自动标记为不兼容。 |
| **手术恐惧症 (Tomophobia)** | 剁刀武器 | I | 非常稀有 | 诅咒附魔。彻底阻止目标在死亡时掉落任何器官。 |

### 按键绑定
类别："Chest Cavity Organ Abilities"（控制设置中可修改）：
- **释放主动能力**：默认 `X`（触发当前选中的器官技能）
- **打开技能轮盘**：默认 `R`（呼出辐射状能力切换轮盘，实时选择激活技能）

## 🛠️ CraftTweaker 开发

模组内置数据只作为基础默认内容。**整合包作者可通过 CraftTweaker 进行 100% 的深度自定义**：

- **器官数据管理 (`mods.chestcavity.OrganData`)**：动态注册全新器官、注册伪器官、增删改器官属性与主动技能、支持物品 Damage / Metadata。
- **胸腔类型定义 (`mods.chestcavity.ChestCavityType`)**：
  - 注册全新的生物胸腔类型；
  - **动态网格尺寸调整**：`setSize(typeId, columns, rows)` / `setSize(typeId, slots)`；
  - 配置固有底分（`addBaseScore`）；
  - 设置默认槽位排布与禁止槽位（`addForbiddenSlot`）；
  - 配置掉落倍率、Boss / 玩家标记与专属特殊器官。
- **实体绑定 (`mods.chestcavity.EntityAssignment`)**：为任意模组实体自由分配或解绑胸腔类型。
- **掉落配置 (`mods.chestcavity.DropManager`)**：配置任意实体的独立器官掉落表与掉落概率。
- **技能与分数定义 (`ScoreManager` / `AbilityManager`)**：自定义分数显示名，注册带回调函数的轮盘主动技能。
- **实时胸腔操作与事件 (`ChestCavityHelper` / 事件系统)**：
  - 在运行时查询/修改实体胸腔内的器官；
  - **在游戏内通过道具动态调整胸腔尺寸**（如使用道具扩容玩家胸腔行列数）；
  - 监听 `onAbilityActivated`、`onOrganEquipped`、`onOrganUnequipped` 事件。

👉 **详细 CrT 开发手册与代码范例，请参阅 [ChestCavity-CRT-API.md](ChestCavity-CRT-API.md)。**

## ⚙️ 配置文件说明

配置文件位于 `config/chestcavity.cfg`：

- **核心设置 (core)**：默认胸腔类型、未开胸器官掉落抢夺加成、天然通用供体概率、排斥反应伤害/间隔、心脏破裂与肾脏衰竭伤害频率、各项器官属性系数、开胸器生命值阈值/开胸伤害/是否允许致死、是否允许打开其他玩家胸腔、死亡是否保留全部胸腔器官、是否完全禁用排斥反应等。
- **扩展与机制 (more)**：闪避跳跃距离、浮力上升速度、水晶合成判定范围与频率、各项防御属性减免比率、反刍消耗时长、潜影弹追踪距离、游泳速度加成等。
- **冷却时间 (cooldown)**：各项主动技能（喷火、恶魂火球、龙弹、吐唾沫、产丝、闪避等）的冷却 Tick 设定。
